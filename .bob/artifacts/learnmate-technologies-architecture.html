Agentic AI — 5 Specialized Agents
1

Student Assessment Agent

Evaluates students' existing skills through two modes: (1) Conversational — IBM Granite Chat model conducts a multi-turn dialogue, then extracts a structured JSON assessment (domain, level, score, strengths, gaps). (2) Quick — self-rating on a 1–5 scale, augmented by Granite Instruct to produce detailed gap analysis.

agents/assessment_agent.py · IBM Granite Chat JSON extraction
2

Learning Path Agent (Roadmap Agent)

Creates personalized 5–8 step roadmaps using IBM Granite Instruct. Takes student profile (domain, skill level, weekly hours, learning style, goals) as a structured prompt and returns a full roadmap JSON. Automatically injects curated free courses from the IBM SkillsBuild catalog into each step, progressively escalating difficulty.

agents/roadmap_agent.py · IBM Granite Instruct Prompt Engineering Course Catalog
3

Course Recommendation Agent

Integrated into the Roadmap Agent and Course Catalog utility. Maps 8 learning domains × 4 skill levels to curated courses from IBM SkillsBuild, freeCodeCamp, Coursera/IBM, The Odin Project, TryHackMe, Google, and more. Courses include metadata: provider, URL, duration, free/paid, rating, and topics covered.

utils/course_catalog.py · IBM SkillsBuild Coursera/IBM freeCodeCamp
4

Progress Tracking Agent

Monitors completed milestones at step-level granularity (0–100% per step, auto-status: not_started / in_progress / completed). Calculates overall roadmap progress. Generates IBM Granite–powered AI feedback on step completion and produces structured weekly progress reports with achievements, focus areas, and estimated time-to-completion.

agents/progress_agent.py · IBM Granite Instruct Progress Logging
5

Adaptive Learning Agent

Updates learning pathways based on student feedback and performance. The adapt_roadmap() method sends current step, overall progress, and student feedback to IBM Granite Instruct, which returns JSON-structured roadmap adjustments (which step to modify, what to change, why). Also powers the AI Coach Chat — a persistent conversational interface with context memory (last 20 messages).

agents/roadmap_agent.py → adapt_roadmap() · IBM Granite Chat Context Memory Adaptive JSON

Key Design Patterns & Decisions

Singleton Granite Client

One shared GraniteClient instance across all agents. Initialised once at startup, reused for all IBM Granite calls, with graceful demo-mode fallback when SDK is absent.

Structured JSON Prompting

All IBM Granite prompts specify exact JSON output schemas. Responses parsed with regex + json.loads. Falls back to structured defaults if parsing fails — ensures the app never crashes on AI output variance.

Progressive Skill Escalation

Course catalog injected per step: every 2 steps the difficulty level escalates (beginner → intermediate → advanced), ensuring smooth learning curve.

Dual Storage Layer

IBM Cloudant for production persistence with automatic in-memory dict fallback for local dev. Same CRUD interface regardless of backend, transparent to agents.

Sliding Context Window

Conversation history capped at 20 messages, last 8–10 passed to Granite per turn — balances context richness against token limits on IBM Cloud Lite tier.

Blueprint-based Routing

Flask Blueprints separate student routes from roadmap routes. Clean separation of concerns: each agent is independently testable and swappable.
